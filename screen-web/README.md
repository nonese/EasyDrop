# Web 屏幕客户端

该目录已包含最小可运行示例：
- `index.html`
- `app.js`

## 运行

```bash
cd /Users/yaojiaqi/Programs/EasyDrop/screen-web
python3 -m http.server 8081
```

打开浏览器访问：
- [http://127.0.0.1:8081](http://127.0.0.1:8081)

## 使用流程

1. 确保后端已启动（`http://127.0.0.1:8000`）
2. 在页面中设置后端地址并点击“保存后端地址”
3. 点击“注册设备”
4. 点击“登录设备”
5. 点击“开始播放”
6. 如需立即同步最新清单，点击“刷新播放列表”
7. 可点击右上角“收起菜单/展开菜单”控制顶部栏显示

说明：
- 后端地址会保存到浏览器本地存储（`localStorage`）
- 下次打开页面会自动回填上次保存的后端地址
- 若本地已保存 `device_id` 与 `device_secret`，打开页面后会自动登录并自动开始播放
- 若自动登录后检测到正在播放视频内容，顶部菜单会默认自动收起

## 当前能力

- 设备注册/登录
- manifest 拉取与版本检测
- 视频/图片循环播放
